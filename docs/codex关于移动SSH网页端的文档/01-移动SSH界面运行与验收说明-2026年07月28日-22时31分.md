# 移动 SSH 界面运行与验收说明

## 当前结论

本轮已落地独立的移动 Web SSH 界面，供手机浏览器验证服务器列表、快速连接、终端布局、系统键盘输入和终端快捷键交互。

当前页面使用模拟服务器和模拟终端输出，不包含真实 SSH 网关、鉴权、凭据保存或网络连接能力。

## 本地运行

在仓库根目录执行：

```bash
npm run mobile-web-dev
```

默认访问地址：

```text
http://127.0.0.1:5580/
```

该命令只启动移动 Web UI，不启动 Electron 桌面端或真实 SSH 服务。

## 生产构建

在仓库根目录执行：

```bash
npm run mobile-web-build
```

构建产物写入 `work/mobile-web/`。该目录属于生成物，不提交到仓库。

## 已实现范围

- 服务器列表及在线状态展示。
- 临时快速连接表单。
- 移动终端页面及模拟命令回显。
- 点击终端或“打开键盘”后聚焦浏览器原生输入控件。
- `Ctrl`、`Esc`、`Tab` 和方向键快捷栏。
- 根据 `visualViewport` 调整页面高度，避免 iPhone 系统键盘遮挡主要操作区。
- iOS 输入属性：关闭自动大写、自动纠错、自动补全和拼写检查，并使用 `16px` 输入字号避免 Safari 自动缩放。
- 顶部与底部安全区适配。

## 验收结果

- `npm run mobile-web-build` 构建成功。
- ESLint 按 Standard 配置检查新增 JavaScript 和 JSX 文件，无错误。
- 在 `390×844` 移动尺寸下验证首页、快速连接和终端页面，未发现布局溢出。
- 在 `320×740` 最窄验收尺寸下，页面宽度与视口一致；终端快捷键仅在自身区域横向滑动。
- 浏览器模拟输入 `whoami` 并回车后，终端正确追加命令和 `deploy` 输出。
- 页面运行期间未发现浏览器控制台错误。
- 移动入口未使用 `window.api`、`window.pre` 或 Electron preload。

## 后续边界

真实可用版本仍需新增受控的 SSH 网关，并将当前模拟数据替换为鉴权后的主机列表、会话创建接口和 WSS 终端数据流。在网关安全方案确认前，不应将现有 Electron 本地服务直接暴露到公网。
